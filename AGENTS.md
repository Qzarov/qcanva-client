# qcanva-client — веб-клиент Q Space / qcanva

Vue 3 + Vite + TypeScript, сборка под браузер и Android (Capacitor). Говорит с хабом `canvas-server-back` по HTTP (`src/api/`) и WebSocket (совместная правка).

Перед работой прочитай [docs/rules.md](docs/rules.md) — правила работы с репо, — затем [docs/README.md](docs/README.md): что уже умеет продукт, как устроен код, API. Общая схема всей системы Q Space — в хабе: [canvas-server-back/docs/architecture/system.md](https://github.com/Qzarov/canvas-server-back/blob/q-space/docs/architecture/system.md).

Документацию обновляй в том же PR (коммите), что и код. Задачи, статус и роадмап — в qcanva, не в `docs/`.
