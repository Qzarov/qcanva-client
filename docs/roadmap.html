MCP: точечные правки текстовых документов

Не вошло в первую версию инструментов text_doc_outline, text_doc_set_checked, text_doc_insert_blocks, text_doc_update_block, text_doc_delete_block (спека от 11.10.2026).

  • Пакетные операции MCP
    text_doc_batch: несколько правок одной ревизией, как canvas_batch.
  • Перенос блоков MCP
    text_doc_move_block: переставить блок или пункт в другое место документа.
  • Перестройка разделов MCP
    Удалить или перенести раздел целиком, вместе со всем, что под заголовком.
  • Правка таблиц по ячейкам MCP
    Сейчас таблица — один блок, адресовать её строки и ячейки нельзя.

Отложено по ходу работ

  • Карточка персонажа через MCP MCP
    Инструменты чтения и изменения листа: характеристики, ХП, снаряжение, заклинания, монеты. Сейчас resource_folder_list отдаёт только метаданные шаблона.
  • Токены MCP с правами и сроком жизни MCP
    Страница /mcp в стиле приложения: выпуск токенов с правами чтение / редактирование / создание / удаление, выбор срока, отзыв. Идёт следующей после точечных правок.
  • Чистка истории документов бэк
    База выросла с 29 МБ (3.09) до 152 МБ (11.10): снимок каждые 50 правок, у бэклога около 21 600 ревизий. Нужен прунинг старых снимков.
  • Починить тесты линейки канваса бэк
    7 тестов CanvasGateway ruler падают на чистом dev.

Дашборд: навигация, фильтры, вид фронт11 из 1111.10.2026 · ca4973e

По фидбеку тестера: дашборд уводил на отдельные страницы разделов, фильтры прятали разделы и папки, «Public» пропадал без возможности вернуть. Влито в dev и main, на проде с 11.10.2026.

  • Home открывает ленту
    Шеврон только сворачивает папки; отдельный пункт Recent (та же лента) убран.
  • Разделы ленты не пропадают из-за фильтров
    Shared, Templates и Public всегда на ленте; сайдбар только прокручивает к ним и больше не уводит на отдельную страницу.
  • «Показать все» раскрывает раздел на месте
    Вместо перехода на страницу раздела; обратно — «Свернуть».
  • Public не теряет переключатель Mine / Others
    При пустом «Mine» секция исчезала вместе с переключателем, вернуть «All» было нельзя.
  • Пустые состояния с учётом фильтров
    «Ничего не подходит под выбранные фильтры» и кнопка «Сбросить фильтры» — на ленте и в папке.
  • Дерево папок в сайдбаре не зависит от фильтров
    Поиск, тип и теги больше не прячут папки и Inbox из навигации.
  • Поиск в Shared
    Запрос «public» находил все расшаренные документы.
  • Одно меню сортировки на кнопку
    На телефоне кнопки Recent и Public открывали два меню сразу.
  • Grid / list на весь дашборд
    Один переключатель для всех разделов ленты и всех папок; он есть и в заголовке папки.
  • Папка без внутреннего скролла
    Содержимое идёт по всей странице, а не в блоке фиксированной высоты.
  • Карточек столько, сколько влезает в ряд
    Вместо жёстких 4: один ряд у Recent, Shared и Templates, четыре — у Public; пересчитывается по ширине окна.
