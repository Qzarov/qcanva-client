## Что нового в 2.0.0

### Новое лого
- Треугольник Q Space вместо старого лого — на сайте, во вкладке браузера, в иконке приложения на Android и на заставке при запуске.

### Дашборд
- **Окно «Добавить»** вместо меню: «Куда», вкладки «Создать» / «Загрузить», квадратные плитки. Канвас, документ, HTML и папка создаются сразу с названием; «Шаблон» раскрывает виды шаблонов. Загрузка: файл в Диск, канвас, HTML, документ из `.md` — тип выбирается до загрузки, каждый файл проверяется, неподходящий можно загрузить как обычный файл.
- **Загрузки — панелью, как на Диске**: каждый файл со своим прогрессом и отменой, затем «Готово», причина ошибки или «Отменено».
- **Выделение нескольких элементов**: галочка на месте иконки типа, Ctrl/⌘-клик, Shift-клик, рамка мышью с пустого места, долгое нажатие на телефоне. Выбираются и канвасы, документы, шаблоны, и файлы Диска в папке.
- **Действия над выбранным** — компактная плашка сверху, только иконки: снять выделение, количество «(N)», выбрать все, переместить, скачать (всё одним zip), удалить (только своё; файлы Диска — в корзину).
- **Дерево папок в боковом меню показывает и файлы**: подпапки, канвасы, документы и файлы Диска раскрытой папки, не больше 10 — остальное одной строкой «… ещё N».
- **«Недавние» считают созданное**; ошибка обновления больше не выглядит как пустой список — «Не удалось обновить» с «Повторить».
- Фильтр и сортировка — между «Добавить» и поиском; в пустом разделе — плитка «+ Добавить»; плавные анимации; без плашки «Pinned»; у интерактивных шаблонов — эмодзи (🐉 D&D-персонаж, 📋 канбан-доска).

### Канвас
- **Плавающая панель узла** над выделением на компьютере: фон (прозрачный, градиент, цвет), текст, рамка (с переключателем «Круглая»), дублировать, слои; блокировка, видимость и удаление — под «⋯». У картинок — название вместо фона и текста, слои и удаление прямо в панели. Правый клик по узлу больше не открывает дублирующее меню — он выделяет узел для панели.

### Для разработчиков
- Выкладка на dev-стенд: `npm run deploy:dev` (сборка в режиме `dev`, откат — `scripts/deploy-dev.sh rollback`).
