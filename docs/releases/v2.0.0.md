## Что нового в 2.0.0

### Дашборд
- **Выделение нескольких элементов** — галочка на месте иконки типа, Ctrl/⌘-клик, Shift-клик для диапазона, рамка мышью с пустого места, долгое нажатие на телефоне. Пока что-то выбрано, клик выбирает, а не открывает; Esc и «Назад» снимают выделение.
- **Блок действий над выбранным** сверху: «Переместить» в папку, «Скачать» (всё одним zip-архивом, с полосой прогресса), «Удалить» (только своё, одним подтверждением).
- **Дерево папок в боковом меню показывает и файлы**: подпапки, канвасы, документы и файлы Drive раскрытой папки, не больше 10 — остальное одной строкой «… ещё N». Файл открывается (файл Drive скачивается) прямо из дерева.
- **«Недавние» считают созданное**: свои ресурсы попадают туда в момент создания; новый файл виден сразу. Ошибка обновления больше не выглядит как пустой список — «Не удалось обновить» с кнопкой «Повторить», прежний список при этом остаётся.
- Фильтр и сортировка — между «Новый» и поиском; их меню больше не уходит под боковое меню.
- В пустом разделе — плитка «+ Добавить».
- Плавные анимации: раскрытие «Показать все / Свернуть», раскрытие папок в боковом меню, вход в папку и выход из неё, переключатели «плитка / список» и «Все / Мои / Чужие».
- Без плашки «Pinned» (закрепление показывает звёздочка); у интерактивных шаблонов вместо плашки с типом — эмодзи (🐉 D&D-персонаж, 📋 канбан-доска).

### Канвас
- **Плавающая панель узла** над выделением на компьютере: заливка, текст, рамка, правка, блокировка, дубль, скрыть; редкое (слои, удаление) — в «Ещё». Меню одного уровня, без палитр поверх палитр.

### Для разработчиков
- Выкладка на dev-стенд: `npm run deploy:dev` (сборка в режиме `dev`, откат — `scripts/deploy-dev.sh rollback`).
