# Этап 1 рефакторинга: подписи канваса в i18n и правила адаптивной раскладки

Дата: 2026-10-13. Ветки: `refactor/canvas-action-labels-i18n` (влита в `dev`),
`refactor/adaptive-layout` (поверх `dev`). Деплой и тег не выполнялись.

## Подписи канваса → i18n

- `nodeActions.ts`: у действия вместо английского `label` теперь `labelKey: MessageKey`;
  `MessageKey` экспортируется из `useI18n.ts`, неверный ключ ловит компилятор.
- `MobileNodeToolbar.vue` переводит ключ через `t()`; «Скрыть/Показать» зависит от состояния.
- `CanvasLoader.vue`: кнопки связи, подпись связи, контекстное меню, панель масштаба
  и ошибка встроенного канваса идут через `t()`. Добавлено 10 ключей (ru/en).
- Тесты: русская подсказка тулбара без латиницы; `CanvasLoader.i18n.test.ts` проверяет
  шаблон (нет статических английских title/placeholder, все ключи есть в обоих языках).

## Адаптивная раскладка

- `src/composables/layoutMedia.ts`: `BREAKPOINTS` и `LAYOUT` — именованные правила
  (`canvasCompact` 640 + телефон боком, `phone` 760, `dashboardPhone` 720,
  `dashboardDrawer` 768, `outlineDocked` 1100), отдельно `COARSE_POINTER` для тача;
  `matchesMedia()` и реактивный `useMediaQuery()` со снятием слушателя.
- Пороги не менялись и не сводились к одному: у каждого своя причина (см. комментарии).
- Переведены места: CanvasLoader, CanvasView, TextDocumentView (тач, редактор, оглавление,
  перетаскивание таблиц), DashboardView (сайдбар, меню карточек, лента), DndSyncStatus,
  DndCharacterSheet, `pointer.ts`.
- JS ↔ CSS: CSS не может импортировать правила, поэтому `layoutMedia.test.ts` проверяет,
  что текст каждого правила совпадает с `@media` в стилях, и что скрипты не содержат
  захардкоженных width/pointer media-запросов.
- Оставлены локальными: пороги листа D&D 559/379px (только для его сетки)
  и расчёты по `innerWidth` для позиционирования меню (это не раскладка).
