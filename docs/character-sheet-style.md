# Карточка персонажа D&D: визуальный стиль

Зафиксировано 6 октября 2026 по состоянию `dev` на `2b9e624`, до начала этапа 1
[плана](character-sheet-roadmap.md). Документ описывает, как карточка выглядит сейчас,
и правила, по которым в неё добавляются новые элементы. Новый блок должен собираться из
того, что здесь перечислено; если не получается — сначала меняется этот документ.

Стили лежат в `<style scoped>` компонента `src/components/DndCharacterSheet.vue` и его
частей `src/components/Dnd*.vue`. Страница вокруг карточки — `src/views/InteractiveTemplateView.vue`.

## Характер

- **Тёмное зелёное стекло.** Полупрозрачные панели на тёмной странице, тонкая
  зеленоватая рамка, блик по верхней кромке.
- **Один акцент — кислотно-зелёный `#00ff00`.** Им отмечено только то, что активно или
  по чему бросают: выбранная вкладка, включённое состояние, владение навыком, кнопка
  атаки, полоса HP, итог броска.
- **Значения читаются как текст.** Поле ввода в покое не имеет рамки и фона; рамка
  появляется при наведении, зелёное кольцо — в фокусе.
- **Плотно.** Это игровой лист, а не форма: мелкие подписи, крупные числа, минимум воздуха.

## Токены

Объявлены на корне `.dnd-cs` и наследуются дочерними компонентами.

| Токен | Значение | Для чего |
|---|---|---|
| `--dnd-glass-bg` | `rgba(13, 17, 14, 0.72)` | фон больших панелей |
| `--dnd-glass-border` | `rgba(130, 210, 155, 0.28)` | любая рамка внутри карточки |
| `--dnd-glass-highlight` | `rgba(255, 255, 255, 0.10)` | внутренний блик по верхней кромке |
| `--dnd-glass-accent` | `#00ff00` | акцент: текст, рамка, заливка индикаторов |
| `--dnd-glass-accent-soft` | `rgba(0, 255, 0, 0.16)` | фон активного элемента и кнопок действий |
| `--dnd-glass-accent-glow` | `rgba(0, 255, 0, 0.36)` | свечение активного элемента |
| `--dnd-glass-radius` | `20px` | радиус больших панелей |
| `--dnd-text-dim` | `#a7c8b4` | подписи, вторичный текст, неактивные кнопки |

Основной текст — `var(--ui-text)`. Ошибки и некорректный ввод — `var(--ui-danger-foreground)`.

Правила:

- Цвет рамки, акцента и приглушённого текста берётся только из токенов. Новый
  литерал цвета в стилях карточки — повод остановиться.
- Полупрозрачные белые заливки (`rgba(255, 255, 255, …)`) пока записаны литералами.
  Используйте существующие ступени, а не новые: `.03` — чип и вкладка в покое,
  `.04`–`.05` — строка списка и кнопка, `.06` — строка под курсором.
- Значения `--dnd-glass-*` совпадают с тёмными `--ui-glass-*` из `src/style.css`.
  Менять их нужно вместе, пока дубль не убран (см. «Известные отступления»).

## Поверхности

Три уровня, вложенные друг в друга. Четвёртого нет.

| Уровень | Класс | Вид | Где |
|---|---|---|---|
| Панель | `.dnd-glass` | фон-токен + градиент, рамка, радиус 20, тень, **размытие 18 px** | верхняя карточка, пассивные значения, состояния, панель вкладки |
| Внутренняя карточка | `.dnd-cs-ability`, `.dnd-cs-proficiencies` | градиент на тёмной подложке, рамка, радиус 14, **без размытия** | характеристики, владения |
| Строка | `.dnd-cs-*-row`, `.dnd-weapon-attack` | белая заливка `.025`–`.05`, рамка, радиус 12 | атака, умение, предмет, цель, заклинание |

- `backdrop-filter` стоит только на панелях. Их на экране единицы; на строках и
  кнопках размытия нет — их десятки, и это дорого.
- Вложенный блок настроек внутри строки (поля оружия) — пунктирная рамка, радиус 10.
- Панель не кладётся в панель.

## Форма

| Радиус | Что |
|---|---|
| `20px` | панель |
| `14px` | внутренняя карточка, тост |
| `12px` | строка списка, пунктирная кнопка «добавить», всплывающее меню |
| `8px` | поле ввода, квадратная кнопка, кнопка действия |
| `999px` | вкладки, чипы, кнопки бросков, переключатель «Преим. / Помеха», полосы |

Рамка везде `1px`. Пунктир — только у «добавить» и у вложенного блока настроек.

## Элементы

| Элемент | Класс | Вид |
|---|---|---|
| Поле ввода | `.dnd-cs input`, `textarea` | прозрачное; наведение — заливка `.045` и рамка; фокус — тёмный фон, акцентная рамка, кольцо `0 0 0 3px` из `accent-soft` |
| Поле в дочернем компоненте | как в `DndWeaponFields` | рамка и заливка `.045` видны всегда; фокус — как выше |
| Кнопка действия | `.dnd-cs-hp-actions button`, `.dnd-roll-attack`, `.dnd-weapon-attack-roll` | фон `accent-soft`, радиус 8, текст `--ui-text`; главная — с акцентной рамкой и жирным текстом |
| Кнопка броска | `.dnd-cs-roll` | пилюля, приглушённый текст, число белым; наведение — акцент и свечение |
| Квадратная кнопка | `.dnd-cs-hp-btn` 24 px, `.dnd-cs-row-remove` 26 px, `.dnd-cs-weapon-toggle` 30 px | рамка, радиус 8; наведение — акцент, у удаления — красный `#ff6b6b` |
| «Добавить» | `.dnd-cs-add` | пунктирная рамка, радиус 12, приглушённый текст; наведение — акцент |
| Вкладка | `.dnd-cs-tabs button` | пилюля; активная — акцентный текст, `accent-soft`, свечение |
| Чип | `.dnd-cs-state-list button`, `.dnd-cs-prof-group label` | пилюля; включённый — акцентный текст на `accent-soft` |
| Точка-индикатор | `.dnd-cs-pip` | кружок 12 px; пустой — рамка, включённый — акцентная заливка со свечением, экспертиза — кольцо, половина — приглушённая заливка |
| Полоса | `.dnd-cs-hp-bar`, `.dnd-cs-xp-bar` | тёмная дорожка `rgba(0,0,0,.45)` с рамкой, акцентная заливка |
| Переключатель | `.dnd-roll-mode` | сегменты в одной пилюле, выбранный — `accent-soft` и акцентная обводка |

Состояния одинаковы у всех: отключённое — `opacity: .45` и обычный курсор; фокус с
клавиатуры виден (кольцо или `outline` акцентом); переходы 130–200 мс.

## Окна поверх карточки

Диалоги, меню и подсказки вынесены в `body` через `<Teleport>` и **не видят токены
`.dnd-cs`**. Они собраны на общих токенах приложения:

| Что | Вид |
|---|---|
| Диалог (`DndHpDialog`, `DndRollLog`, `DndWeaponCatalog`) | затемнение `rgba(0,0,0,.45)`, окно `--ui-surface-solid`, рамка `--ui-border`, радиус 16, тень `--ui-glass-shadow`; кнопки — общие `.btn-ghost` и `.btn-primary`, по центру |
| Меню и подсказка | `--ui-surface-solid`, `--ui-border`, радиус 12, пункты с радиусом 8, наведение `--ui-surface-subtle` |
| Тост броска (`DndRollToasts`) | тёмное стекло с зелёной рамкой, радиус 14; крит — усиленное свечение, провал — красная рамка |

Новое окно берёт вид у существующего того же типа. Диалог закрывается по Esc и по
клику на затемнение, держит фокус внутри и возвращает его на кнопку, которой открыт.

## Раскладка

- Корень — колонка с шагом 14 px: верхняя карточка, строка «пассивные значения +
  состояния», тело в две колонки (характеристики слева, вкладки справа).
- Отступы внутри панели 12–16 px, внутри строки 8 px, между строками 8 px, между
  кнопками 6 px.
- Единственная точка перелома — `760px`. Ниже неё всё в одну колонку, характеристики
  остаются по две в ряд.
- На телефоне кнопки, которые нажимают каждый ход, — не ниже 44 px.
- Ничто не выходит за ширину карточки на 320 px: длинные подписи переносятся
  (`overflow-wrap: anywhere`), ряды кнопок заворачиваются (`flex-wrap`).

## Технические правила

- Стили `scoped`: правила родителя для `input` и `button` не действуют внутри дочернего
  компонента. Дочерний компонент описывает свои поля сам, по образцу `DndWeaponFields`.
- Компонент, который может оказаться вне `.dnd-cs`, подставляет запасные значения:
  `var(--dnd-glass-border, var(--ui-border))`, как в `DndFormulaButton`.
- У числовых полей в плотных местах скрыты стрелки (`appearance: textfield`).
- У каждого поля и кнопки без текста есть `aria-label` — на них опираются тесты
  `tests/character-sheet-header.spec.ts`.
- Подписи пока только на русском.

## Известные отступления

Это текущее состояние, а не образец. Новые элементы не должны их повторять, а чинить
их стоит отдельной задачей, не заодно с фичей.

1. **Светлая тема не поддержана.** Токены `--dnd-glass-*` тёмные при любой теме, а
   текст берётся из `--ui-text`, который в светлой теме тёмный. Карточка в светлой
   теме — тёмное стекло с плохо читаемым текстом
   ([снимок](images/character-sheet/sheet-desktop-light.png)).
2. **Токены продублированы.** `--dnd-glass-*` повторяют `--ui-glass-*` из
   `src/style.css`. Перевод карточки на общие токены закрыл бы и пункт 1.
3. **Тост броска на литералах** (`#00ff00`, `#8fe0a4`, `#eaf6ee`) — он вне `.dnd-cs` и
   токенов не видит. Журнал бросков подсвечивает крит и провал своими литералами.
4. **`transition: all`** в нескольких местах вместо перечисления свойств.
5. **Мелкий мусор в стилях:** правило `.dnd-cs-hp-bar` объявлено дважды, в мобильном
   блоке остались правила для несуществующего `.dnd-cs-attack-head`.

## Перед тем как добавить элемент

1. Он собран из уровней и элементов выше? Если нужен новый вид — сначала правка здесь.
2. Цвета только из токенов, заливки — из существующих ступеней.
3. Акцент стоит только на активном и на том, по чему бросают.
4. Размытие не добавлено.
5. Проверено на 320, 390, 760 и 1280 px; на телефоне частые кнопки не ниже 44 px.
6. Работает с клавиатуры, фокус виден, у кнопок без текста есть `aria-label`.
7. Только чтение (`readonly`) выглядит и ведёт себя корректно: поля не редактируются,
   кнопки отключены.

Для этапа 1 это значит:

| Новое | Из чего собрать |
|---|---|
| Спасброски от смерти | два ряда точек `.dnd-cs-pip` (провалы — красным `#ff6b6b`), кнопка броска `.dnd-cs-roll`, блок внутри верхней карточки без новой панели |
| Кости хитов | подпись и число как у боевых параметров (`.dnd-cs-stat`) |
| «Короткий отдых», «Длинный отдых» | кнопки действия, как «Лечение» и «Урон» |
| Диалог отдыха | по образцу `DndHpDialog` |
| Восстановление умения | `select` в строке умения, оформленный как в `DndWeaponFields` |

## Как вести этот документ

Меняется вид карточки — в том же изменении меняются правила и переснимаются эталоны.
Устранённое отступление вычёркивается из списка.
