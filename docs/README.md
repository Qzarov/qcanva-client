# Документация веб-клиента QCanva (qcanva-client)

`qcanva-client` — веб-клиент экосистемы Q Space / qcanva на стеке Vue 3 + Vite + TypeScript. Приложение собирается для современных браузеров и мобильных устройств под управлением Android (через Capacitor). Клиент взаимодействует с серверным хабом `canvas-server-back` по протоколам HTTP (`src/api/`) и WebSocket (совместное редактирование, присутствие и чат).

---

## Порядок чтения документации

1. **[rules.md](rules.md)** — **читать в первую очередь**. Правила работы с репозиторием, обязательные проверки перед отправкой PR (`test:unit`, `build`), правила изоляции веток, работа с памятью на общем стенде и ограничения для разработчиков и агентов.
2. **[features.md](features.md)** — функциональная карта всех возможностей клиента по экранам и функциональным областям (авторизация, дашборд, диск, фото, текстовые и HTML-документы, канвасы, доски, листы персонажа, совместная работа, Q Control, настройки, Android-специфика). Включает таблицу соответствия UI-функций эндпоинтам хаба и список API-функций, не выведенных в интерфейс.
3. **[architecture.md](architecture.md)** — архитектурное устройство фронтенда: карта маршрутов и логика ремонтирования, каталог представлений и компонентов, организация модульного состояния (без Pinia), структура API-слоя, шина реального времени WebSocket/Yjs, интернационализация i18n, флаги окружения, особенности Android-сборки и тестовые наборы.
