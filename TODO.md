# Canvas Server — План разработки

## 1. Бэкенд
- Хранение canvas-файлов в БД
- REST API для CRUD операций с canvas
- Раздача canvas по уникальной ссылке

## 2. Роутинг
- Уникальные URL `/canvas/:id` для каждого canvas
- Страница 404 для несуществующих canvas

## 3. Режим просмотра
- [x] Read-only просмотр canvas с pan/zoom
- [x] Отображение text, link, group нод
- [x] Markdown рендеринг внутри нод
- [x] Стрелки (edges) между нодами
- [ ] Read-only режим для тех, кто открыл по ссылке без прав редактирования
- [ ] Полноценный режим редактирования для владельца и пользователей с правами

## 4. Редактирование
- [x] Перетаскивание блоков (drag & drop)
- [ ] Редактирование текста нод
- [ ] Создание новых нод
- [ ] Удаление нод
- [ ] Создание/удаление связей (edges)
- [ ] Ресайз нод

## 5. Загрузка canvas
- [ ] Загрузка `.canvas` файлов (Obsidian формат)
- [ ] Создание нового пустого canvas через интерфейс
