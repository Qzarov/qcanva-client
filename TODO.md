# Canvas Server — План разработки

## 1. Ноды
- [x] Отображение text, link, group нод
- [x] Markdown рендеринг внутри нод
- [x] Перетаскивание блоков (drag & drop)
- [x] Ресайз нод
- [x] Редактирование текста нод (двойной клик)
- [x] Создание новых нод (двойной клик по пустому месту)
- [x] Удаление нод (Delete/Backspace)
- [x] Контекстное меню (смена цвета, удаление, дублирование)
- [x] Callouts в markdown (`> [!warning]`, `> [!note]`)
- [ ] File-ноды — отображение картинок, markdown-файлов, PDF
- [ ] Link-ноды — iframe-превью сайта

## 2. Связи (edges)
- [x] Стрелки (bezier-кривые) между нодами
- [x] Создание связей — drag от коннектора ноды к другой
- [x] Удаление связей (выделение + кнопка/Delete)
- [x] Редактирование лейблов на стрелках (двойной клик)
- [x] Лейблы с фоном на стрелках
- [x] Стили стрелок — solid/dashed/dotted, 6 цветов

## 3. Взаимодействие
- [x] Pan & zoom (мышь, колёсико, touch/pinch)
- [x] Мультиселект (Shift/Ctrl + клик, рамкой)
- [x] Undo/redo (Ctrl+Z / Ctrl+Shift+Z)
- [x] Copy/paste нод (Ctrl+C / Ctrl+V)
- [x] Snap to grid (24px)
- [x] Горячие клавиши (Ctrl+A, Escape, Delete)

## 4. Навигация
- [x] Minimap (мини-карта в углу)

## 5. Сохранение
- [x] Экспорт в `.canvas` формат
- [x] Импорт `.canvas` файлов
- [x] Создание нового пустого canvas

## 6. Бэкенд
- [x] Хранение canvas-файлов в БД (SQLite + TypeORM)
- [x] REST API для CRUD операций с canvas
- [x] Раздача canvas по уникальной ссылке

## 7. Роутинг
- [x] Уникальные URL `/canvas/:id` для каждого canvas
- [x] Read-only режим для просмотра по ссылке (public canvas)
- [x] Режим редактирования для пользователей с правами

## 8. Авторизация
- [x] Регистрация и вход (email/пароль) — API
